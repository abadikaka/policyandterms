The path · Dhp 273

Eight factors, one path

The verse singles out the Noble Eightfold Path and the Four Noble Truths. It directs the learner toward a coherent path rather than scattered achievements.

Editorial summary · Not a scripture translation

Which path is named?

A closer look

  1. The Noble Eightfold Path

The eight factors are explained separately in early discourses such as SN 45.8. This verse names the path; it does not list all its details.
