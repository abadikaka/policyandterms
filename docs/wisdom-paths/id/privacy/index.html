Kebijakan privasi Wisdom Paths

Wisdom Paths disediakan oleh Michael Abadi Santoso. Aplikasi menyimpan perjalanan dan bahasa pilihan Anda, pelajaran yang selesai dan disimpan, tanggal ulasan ulang Injil, pasangan perbandingan Gita, serta tanggal latihan Buddhis di perangkat Anda. Jawaban tantangan dan renungan pribadi tidak disimpan.

Kami tidak menyediakan akun aplikasi, iklan, atau analitik pihak ketiga. Kemajuan belajar tidak dikirim ke server kami. Data aplikasi di perangkat dapat disertakan dalam cadangan perangkat. Menghapus aplikasi menghapus data lokalnya; cadangan yang sudah ada harus dikelola terpisah dalam pengaturan Apple Anda.

Apple memproses pembelian keanggotaan dan memberikan status langganan melalui StoreKit. Kami tidak menerima rincian kartu pembayaran Anda. Apple dapat memproses data pembelian dan diagnostik menurut kebijakan serta pengaturan perangkatnya sendiri.

Situs ini dihosting oleh GitHub Pages, yang dapat memproses informasi koneksi seperti alamat IP. Halaman ini tidak memakai skrip analitik atau cookie pelacakan. Tautan sumber eksternal memiliki praktik privasi sendiri.
